# Hi, I'm Sindre

I'm Sindre Alstad Wilting, a software engineer in Oslo, working at Everdeen and [@Cratis](https://github.com/Cratis), an event-sourcing platform.

I like event sourcing, .NET, Rust command-line tools and tooling for AI coding agents. Most of what is below started as a tool I wanted myself.

## Featured projects

### AI coding-agent tooling

My setup and extensions for the pi coding agent.

- [**pi-setup**](https://github.com/woksin/pi-setup): My pi coding agent setup: global rules, subagents, extensions, installer, lanes and pi-train
- [**pi-jobs**](https://github.com/woksin/pi-jobs): Background shell jobs and watches for pi that wake the agent when they finish, at zero token cost
- [**pi-context-budget**](https://github.com/woksin/pi-context-budget): Structured context handoffs and bounded long sessions for pi, in the same process
- [**pi-recover**](https://github.com/woksin/pi-recover): Pi extension that recovers unfinished subagents, workflows and jobs after a crash or usage limit with /recover
- [**pi-orch**](https://github.com/woksin/pi-orch) (experimental): durable order bus, batched candidate PRs and a shared GitHub poller for many sessions

### Rust CLIs

Each installs with Homebrew from its own tap.

- [**reap**](https://github.com/woksin/reap): Find stale developer junk and prune only what you can afford to lose: branches, worktrees, build artifacts, Docker, caches
- [**workstats**](https://github.com/woksin/workstats): Local-first Git and AI work analytics across CLIs, IDEs and APIs: fast Rust, open JSONL, zero telemetry
- [**gearprice**](https://github.com/woksin/gearprice): What guitar gear costs on Reverb right now, from asking and sold prices, and what price class it sits in

### Apps

- [**Varde**](https://github.com/woksin/Varde): Self-hosted family life OS: chores, rewards, meals and a shared calendar on a kitchen wall tablet
